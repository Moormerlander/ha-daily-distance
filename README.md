# Daily Distance for Home Assistant

**Version 0.5.2**

A local Home Assistant custom integration that calculates driven distance by integrating a speed sensor. The source speed can be reported in **km/h or mph**.

## Features

- Use any Home Assistant `sensor.*` speed entity
- Select the speed sensor in the UI or enter its entity ID manually
- Choose **km/h or mph** for the source speed sensor
- Distance output is automatically reported as **km or mi**
- Configurable minimum speed (default: 1.0 in the selected speed unit)
- Configurable day boundary (default: 00:00)
- Daily distance: today and yesterday
- Distance totals for week, month and year
- Lifetime total distance
- Persistent storage across Home Assistant restarts
- Daily values for the last 30 days as an attribute of the Today sensor
- Only the lifetime total uses `total_increasing`; period values use `measurement`
- Data gaps longer than five minutes are not interpreted as driving
- No vehicle-specific code or hard-coded sensor entity
- English, German and Dutch UI translations included

## Installation via Home Assistant Marketplace

Home Assistant 2026.11 and newer includes the Marketplace. The repository can be installed as a custom repository before it is accepted into the public Marketplace catalog.

Repository:

`https://github.com/Moormerlander/ha-daily-distance`

Open **Settings → Marketplace → Add repository by URL**, enter the repository URL, and select **Integration**.

The Marketplace installs the integration into `custom_components/daily_distance`.

## Configuration

Go to **Settings → Devices & services → Add integration → Daily Distance**.

You can select a speed sensor from the entity selector or enter its entity ID manually.

### Speed unit

Choose the unit used by the source sensor:

- **km/h** — output distance is in km
- **mph** — output distance is in mi

The calculation is internally normalized to km/h and converted back to the selected distance unit for the sensors.

### Minimum speed

The default minimum speed is 1.0 in the selected speed unit. Values below this threshold are treated as zero speed, preventing GPS drift while stationary from adding distance.

### Day boundary

The default day boundary is 00:00. It can be changed during setup.

## Sensors

The integration creates six distance sensors:

- Today
- Yesterday
- Week
- Month
- Year
- Total

The exact entity IDs are generated by Home Assistant from the configured name and entity registry.

## Data handling

Distance is calculated once per second from the current speed. A sensor that keeps the same speed value therefore continues to accumulate distance correctly. If the source sensor is unavailable or a calculation gap exceeds five minutes, the gap is ignored rather than counted as driving.

Distance data is persisted to Home Assistant storage in batches rather than writing to disk for every one-second calculation.
